一、上传到 GitHub Pages
这次不能只传 index.html，要传这些文件/文件夹：
- index.html
- manifest.webmanifest
- sw.js
- favicon.svg
- icons 文件夹（3 张 png）

方法：
1. 打开 https://github.com/3grc/abc/upload/main
2. 把上面所有文件和 icons 文件夹一起拖进去
3. 点 Commit changes
4. 等 1 分钟，打开 https://3grc.github.io/abc/
5. 手机上打开后，用浏览器菜单“添加到桌面”

第一次打开后，PWA 会缓存页面；以后断网也能打开。
AI、个人同步、图片识别仍然需要联网。

二、备份与恢复
- 自动快照：每次数据变化后自动保存，保留最近 3 份
- 设置页有“备份与恢复”卡片，可“立即快照”“恢复快照”
- 快照只在当前浏览器，能防误删/误导入，但不能防“清理浏览器数据”
- 电脑 Chrome/Edge 可以“开启自动备份到文件”，授权后每次修改自动写入你选的 JSON 文件
- 手机浏览器不允许静默写文件，请用“导出 JSON”或个人同步
- 导入 JSON 现在是合并：新增、更新、保留本机较新，不会删除现有错题
- 超过 7 天没导出，底部会出现“该备份了”提醒

三、图片识题（可选）
1. 打开 https://bailian.console.aliyun.com/
2. 开通百炼，创建 API-KEY
3. 错题本 → 设置与备份 → 图片识题
4. 粘贴 Key，保存
5. 录入错题时，顶部有“拍照录题”，点它会打开相机窗口
6. 第一次会问“是否允许使用相机”，点允许；拍完点“拍下这道题”
7. 如果浏览器不支持相机窗口，会自动改从相册选
8. 识别结果会填入题干；公式用 LaTeX 表示，请自己核对

说明：
- 百炼 Key 和 DeepSeek Key 不通用
- 按量计费；不配置也能手动输入题干
- 数学公式识别后建议人工校对

四、考研大纲知识点树
- 录入/编辑错题时，会出现“考研大纲”
- 先选章节，再选知识点；选完自动填入“知识点”
- 也可以选“自定义”手填
- 统计分析页新增“大纲章节掌握度”
- 点“浏览大纲”可以看所有科目/章节/知识点

五、AI 错题教练（可选）
1. 打开 https://platform.deepseek.com/api_keys
2. 创建 Key，复制 sk-...
3. 设置与备份 → AI 错题教练 → 粘贴 Key → 保存并测试
4. 打开任意错题，详情页底部有“AI 分析”“AI 相似题”
5. 设置页有“本周学习建议”“网站改进建议”

默认开启“只给提示，不直接给答案”：
- 先给考点、卡点、第一步提示
- 自己想过之后，点“看完整解析”才给完整解法
- 设置页可以关闭这个开关

AI 出的相似题：
- 会先显示“尚未复核”
- 点“AI 复核答案”，AI 会独立算一遍，核对答案和解析
- 复核发现问题会列出，并给出修正答案，可点“采用修正答案”
- 必须勾选“我已核对”才能加入错题本
- 加入后详情页会标记“AI 生成 · 已核对”

公式渲染：
- AI 输出里的 $...$ / \(...\) 公式会自动排版
- 公式渲染用 KaTeX CDN；如果网络加载失败，公式会保留为原始文本
- 第一次打开需要联网加载公式组件

同一道题分析过一次会缓存，不重复扣费。

六、个人同步（可选）
1. 打开 https://github.com/settings/tokens
2. Generate new token (classic)
3. 只勾选 gist，不要勾 repo
4. 设置与备份 → 个人同步
5. 第一台设备填 Token，点“创建新 Gist 并连接”
6. 第二台设备填同一个 Token + Gist ID，点“连接已有 Gist”

七、今日计划 / 连续天数
首页底部新增“今日计划”：
- 今日待复习、今日已复习
- 本周活跃天数
- 连续复习天数
- 今日进度条
- 一键开始今日复习

八、手机底部导航 / 设置分组
- 手机/平板窄屏底部有 5 个固定入口：总览、错题本、复习、统计、设置
- 设置页按“AI 工具、同步与备份、学习设置、数据管理、其他”分组
- 桌面端仍使用左侧导航

九、AI 聊天助手
- 页面右下角有“AI 助手”按钮
- 可以自由提问：分析薄弱点、制定计划、解释知识点、总结错因
- 会结合当前错题数据回答
- 需要先在设置里配置 DeepSeek Key
- 对话只保存在本机；可以清空
- 每条消息都会调用 DeepSeek，按量计费

十、配置向导 / 扫码配对
- 设置页最上面是“配置向导”，显示 AI、同步、备份是否完成
- “一键诊断”会检查 AI、Gist、备份、相机、公式
- 电脑配置好个人同步后，点“手机扫码配对”
- 手机会打开一个二维码，扫码后自动填入 Gist ID 和 Token
- 二维码里包含 Token，只给自己的手机扫，不要截图发人
- 也可以复制 Gist ID 或配对链接手动发到手机

十一、AI 自动识别知识点
- 录入错题时，大纲下面有“AI 识别知识点”
- 默认开启“保存时自动识别”：保存新题时自动填学科、章节、知识点、具体考题项目、题型、错因、标签
- “具体考题项目”不是“选择题/解答题”，而是知识点下更细的考法，例如“求极限”“无穷小阶的比较”“间断点类型判断”
- 不想自动识别，取消勾选即可；也可以点按钮手动识别
- 需要先配置 DeepSeek Key
- 每次识别会消耗少量 DeepSeek 费用
- 刚保存时如果 AI 识别较慢，等一两秒属正常

十二、知识框架 / 题型 / 思维导图
- 统计分析页 → “大纲章节掌握度” → “浏览大纲”
- 按“科目 → 章节 → 知识点”显示每层有多少道题、多少未掌握
- 每个知识点后面会显示“具体考题项目”的分布，例如“求极限2 · 无穷小比较1”
- 点知识点会跳到错题本并按它筛选
- 点“思维导图”会打开可视化知识树：
  - 科目 → 章节 → 知识点
  - 每个知识点显示题量和具体考题项目
  - 红色边框表示有未掌握
  - 可以切换科目
  - 点知识点也会跳到错题本

十三、显示与安装 / 跨浏览器
- 设置页最下面有“显示与安装”
- “进入全屏”：临时隐藏浏览器地址栏
- “安装到桌面”：Edge/Chrome 可安装成独立应用，之后打开没有地址栏
- 华为浏览器可能只能创建快捷方式，地址栏仍会出现；建议用 Edge 安装，或做 APK
- “界面密度”可切换舒适/紧凑
- 全屏后变回手机布局：点“桌面全屏”，不要点普通全屏；它会先锁定左侧栏再全屏
- 不同浏览器数据默认独立：
  - 每个浏览器都要连接同一个 Gist，才会显示同一份错题
  - 在已连接的浏览器点“复制配对链接”，到另一个浏览器打开，会自动配置
  - AI Key、图片识别 Key 不会跨浏览器同步，各自填一次

十四、轻量学习台首页
- 首页改成：今日复习、快速录入、最近错题、薄弱知识点、今日计划、AI 助手
- 去掉了大段宣传语和过多图表
- 平板横屏基本一屏能看完
- “开始今日复习”直接进入沉浸复习

十五、沉浸复习模式
- 点“开始今日复习”后全屏复习，没有侧边栏和底部导航
- 顶部：退出、第几道、计时
- 中间：题目、显示答案、答案与解析
- 显示答案后出现 4 个评分按钮
- 快捷键：Space 显示答案、1-4 评分、Esc 退出
- 一轮结束显示本轮总结

十六、完整使用说明
- 压缩包里有一个“使用说明.html”
- 在软件里：设置 → 显示与安装 → 完整使用说明
- 里面包含所有配置、同步、AI、拍照、备份、常见错误和卡住时的处理

十七、注意
- 不配置个人同步时，数据只存本机
- 清理浏览器数据前，一定先导出 JSON
- 不要把 API Key / Token 发给别人
- 图片识别、AI、同步都需要联网；纯本地功能可离线使用
