01. 5 分钟上手

两个常用入口：“安装到桌面”和“使用说明”现在在：① 左侧主导航“使用说明”；② 顶部首次使用提示条；③ 标题栏右侧；④ 设置 → 显示与安装。
  1. 打开 https://3grc.github.io/abc/。
  2. 第一次没有数据，去 设置 → 示例与重置 → 恢复示例数据，或者直接新增错题。
  3. 点首页的 拍照 / 录入错题，写题干、答案、错因。
  4. 保存后，回首页点 开始今日复习，进入全屏复习。
  5. 去 设置 → 备份与恢复 → 立即导出备份，先存一份 JSON。
最小可用配置：什么都不配，也能本地记错题、复习、导出。AI、图片识题、个人同步都是可选的。

02. 安装到桌面 / 地址栏问题

为什么每次打开上面有地址栏？

因为打开的是浏览器里的网页，不是安装后的独立应用。网页快捷方式一定会带浏览器地址栏。

怎么去掉地址栏

  • 电脑 Edge / Chrome：地址栏右侧“安装”图标，或菜单 → 应用 → 安装此站点。
  • Android Edge：菜单 → 安装应用 / 添加到主屏幕。
  • iPhone / iPad：必须用 Safari → 分享 → 添加到主屏幕。
  • 华为浏览器：通常只能创建快捷方式，仍可能显示地址栏；想真正全屏建议用 Edge。

设置 → 显示与安装 里有“桌面全屏”“普通全屏”和“安装到桌面”。桌面全屏会先锁定左侧栏再全屏；普通全屏只隐藏地址栏。

如果一进全屏就变回手机布局：点 桌面全屏，不要点普通全屏。它会先切到桌面布局再全屏。

平板横屏入口

平板用这个地址添加到桌面，会使用横屏 manifest：

https://3grc.github.io/abc/?tablet=1&v=1.5

如果华为浏览器仍然锁竖屏，进设置 → 显示与安装 → 点 横屏模式。

如果安装后仍显示地址栏：卸载旧快捷方式，用 Edge 重新“安装应用”，不要用“添加到桌面”的网页快捷方式。

想要 APK

网页本身可以用 PWABuilder 打包成 APK，但 AI、同步仍需要网络。当前电脑没有 Android 构建环境，不能直接产出 APK。

03. 数据在哪 / 为什么不同浏览器不一样

数据默认只存在当前浏览器的本地存储里。Edge 的数据、Chrome 的数据、华为浏览器的数据是互相独立的。

所以会出现：

  • Edge 里有 20 道题，Chrome 里只有 3 道
  • 平板和电脑内容不一样
  • 换浏览器后 AI Key 也要重新填

让它们一致

  1. 在已经配置好的浏览器完成“个人同步”。
  2. 在另一个浏览器打开同一个网址。
  3. 设置 → 个人同步 → 填同一个 Gist ID + Token，点“连接已有 Gist”。
  4. 或者从已配置浏览器点“复制配对链接”，在新浏览器打开。

AI Key、图片识别 Key 不会同步，每个浏览器要各填一次。

换设备

导出 JSON → 新设备导入 JSON；或者连接同一个 Gist。

04. 个人同步完整配置

个人同步用 GitHub 的 secret Gist 存一份数据，只在你自己的设备之间同步，不是给同学共享。

第一步：创建 Classic Token

  1. 打开 https://github.com/settings/tokens
  2. 左侧点 Tokens (classic)，不是 Fine-grained tokens。
  3. Generate new token → Generate new token (classic)。
  4. Note 填 cuoti，Expiration 选 90 天。
  5. 权限只勾 gist。其他都不要勾。
  6. Generate token，复制 ghp_...。
Fine-grained Token 不支持 Gist，前缀是 github_pat_，不能用。必须用 ghp_ 的 Classic Token。

第二步：电脑创建 Gist

  1. 设置 → 个人同步。
  2. 粘贴 Token，Gist ID 留空。
  3. 点 创建新 Gist 并连接。
  4. 显示“已连接”即成功。

第三步：手机/平板连接

  1. 打开同一个网址。
  2. 设置 → 个人同步。
  3. 填同一个 Token 和同一个 Gist ID。
  4. 点 连接已有 Gist，不要点“创建新 Gist”。

常见错误

提示原因解决
Gist 不存在，或 Token 没有 gist 权限Token 不是 Classic，或没勾 gist重新创建 Classic Token，只勾 gist
Bad credentials / 401Token 失效、复制不完整、被撤销重新生成 Token，所有设备换新 Token
Gist 不存在Gist ID 填错，或 Gist 被删核对完整 ID；或电脑重新创建 Gist
连接后内容不一样两个设备填了不同 Gist ID统一成同一个 ID，点“立即同步”
手机上找不到 Gist ID设置里只显示前 8 位在电脑“配置向导 → 手机扫码配对”里看完整 ID

05. 手机扫码配对

  1. 电脑上先完成个人同步，显示“已连接”。
  2. 设置 → 配置向导 → 手机扫码配对。
  3. 手机相机扫码，自动打开网页并填入 Gist ID 和 Token。
  4. 等它显示“已连接”。
二维码里包含 Token。只给自己的手机扫，不要截图发群。配对链接也一样。

手机扫不开：用手机浏览器手动打开配对弹窗里的链接；或手动填 Gist ID + Token。

不要在手机上点“创建新 Gist”，那会新建一份空数据。

06. AI 配置与使用

获取 DeepSeek Key

  1. 打开 https://platform.deepseek.com/api_keys
  2. 注册/登录，创建 API Key。
  3. 复制 sk-...。
  4. 设置 → AI 工具 → AI 错题教练 → 粘贴 → 保存并测试。

能做什么

  • 错题详情底部：AI 分析、AI 相似题
  • 右下角：AI 学习助手聊天
  • 设置：本周学习建议、网站改进建议
  • 录题保存：自动识别学科/章节/知识点/具体考题项目/题型/错因/标签

提示模式

默认“只给提示，不直接给答案”。先看提示自己走一步，需要时点“看完整解析”。设置里可以关闭。

常见问题

提示原因解决
401 / API Key 无效Key 错、复制不完整、已删除重新创建 Key，重新粘贴
402 / 余额不足DeepSeek 账户没余额充值；不充值就先用本地功能
429 / 请求太频繁连续点击太快等一会儿再试
AI 分析很慢网络或模型排队等 5-15 秒；不要重复点
自动识别太慢保存时要等 AI 返回等 1-3 秒；或关闭“保存时自动识别”
AI 相似题算错模型会出错点“AI 复核答案”，再进行人工核对
AI 分析会缓存；同一道题不会重复扣费。题目改了才会重新分析。

07. 拍照 / 图片识题

图片识题需要另一个 Key

图片识题用阿里云百炼 Qwen-VL，和 DeepSeek Key 不通用。

  1. 打开 https://bailian.console.aliyun.com/
  2. 登录/开通百炼。
  3. 页面底部点 API Key → 创建 API Key。
  4. 复制 sk-...。
  5. 错题拾遗 → 设置 → AI 工具 → 图片识题 → 保存 Key。

拍照流程

  1. 新增错题 → 顶部“拍照录题”。
  2. 允许相机权限，拍下题目。
  3. 点“识别图片文字”，结果填入题干。
  4. 公式用 LaTeX 表示，识别后自己核对。

常见问题

问题原因 / 解决
点拍照没反应浏览器不支持页内相机；会退回相册。用 Edge，或先系统相机拍照再上传。
相机权限被拒绝浏览器设置 → 网站权限 → 相机 → 允许；必须 HTTPS。
识别失败检查百炼 Key、余额、图片清晰度；公式题识别后手动修正。
图片太大会自动压缩到长边 1400px；超过 12MB 的图片会被拒绝。
图片题 AI 不分析在编辑里补一句文字题干，AI 才能分析；图片识别只负责转文字。

08. 录题与自动识别

必填：题干（或至少一张图片）、错因。学科默认会带入。

字段说明

  • 学科：政治、英语一/二、数学一/二/三、专业课一/二、管综。
  • 章节：大纲模块，例如高等数学、线性代数。
  • 知识点：具体知识，例如多元积分学。
  • 具体考题项目：这一知识点具体怎么考，例如“求极限”“无穷小阶的比较”。
  • 题型：选择题、填空题、解答题等。
  • 错因：不要只写“粗心”，写具体错在哪一步。

AI 自动识别

大纲下面有“AI 识别知识点”和“保存时自动识别”。保存时会自动填学科、章节、知识点、具体考题项目、题型、错因、标签。

自动识别会消耗少量 DeepSeek 费用。不想花钱就取消勾选“保存时自动识别”，或手动填写。

保存没反应

  • 检查题干和图片是否至少有一个。
  • 检查是否在等 AI 自动识别；等 1-3 秒。
  • 浏览器存储满了：先导出 JSON，再清理旧图片。
  • 手机键盘挡住保存：往下滑或收起键盘；底部保存按钮固定在弹窗下方。

09. 复习 / 今日计划

今日计划

首页显示今日待复习、已复习、连续天数、掌握率。到期题按 nextReview 计算。

沉浸复习

  1. 点“开始今日复习”，进入全屏。
  2. 先自己回忆，按 Space 或点按钮显示答案。
  3. 按 1—4 或点按钮评分：又忘了 / 有点难 / 想起来了 / 很熟练。
  4. Esc 退出；一轮结束显示总结。

评分怎么选

  • 又忘了：明天再来。
  • 有点难：2 天左右。
  • 想起来了：按上次间隔拉长。
  • 很熟练：拉得更长。

不要为了连续天数乱点“很熟练”；按真实感受选，系统才会安排对。

10. 知识框架 / 思维导图

统计分析 → 大纲章节掌握度 → 浏览大纲 / 思维导图。

浏览大纲

按科目 → 章节 → 知识点显示题量、未掌握数、具体考题项目分布。点知识点跳到错题本筛选。

思维导图

可视化树：科目 → 章节 → 知识点 → 具体考题项目。红色边框表示有未掌握，可以切换科目。

为什么是空的 / 不准

  • 题目没有选章节/知识点：编辑旧题，点“AI 识别知识点”。
  • 知识点不在大纲里：选“自定义”，或手动填写具体知识点。
  • 不同题目写法不同：统一使用大纲里的名称，统计才准。

11. 备份 / 恢复 / 导入

三种备份

  • 导出 JSON：独立文件，最重要。换设备、清缓存前必须做。
  • 本机快照：自动保留最近 3 份，防误删/误导入，但不能防清理浏览器。
  • 个人同步：Gist 云端副本，自动同步，但不是版本备份。

导入是合并，不是覆盖

导入时会比较 updatedAt：新增没有的题，更新更晚的题，保留本机更新的题。不会删除现有题。

电脑自动备份到文件

设置 → 备份与恢复 → 开启自动备份到文件，选一个 JSON 路径。仅 Chrome/Edge 电脑支持；手机浏览器不支持静默写文件。

常见问题

问题解决
“该备份了”一直出现点“立即备份”会导出并标记；或点“稍后”当天不再提醒。
恢复快照后数据变旧快照是过去某一刻；恢复前先导出当前数据。
导入后没有变化本机题目 updatedAt 更新，导入的较旧；确认导入文件时间。
清理浏览器后数据没了本地数据和快照都丢了；只能从 JSON 备份或 Gist 恢复。

12. 更新 / 缓存 / 旧版界面

更新后打开 https://3grc.github.io/abc/?v=1.5，版本号可以强制绕过缓存。

  • 电脑：Ctrl + F5 强制刷新。
  • 手机：清除该网站数据，或完全关掉浏览器再打开。
  • 安装到桌面的 PWA：关闭应用，重新打开；仍旧就卸载重装。
清除网站数据会删除本地错题。先导出 JSON，或确认 Gist 已同步。

Service Worker

PWA 会缓存页面；更新后如果仍显示旧版，通常是 Service Worker 缓存。版本号查询参数能帮助绕过。

14. 安全与隐私

  • DeepSeek Key、百炼 Key、GitHub Token 只保存在当前浏览器，不写进网页代码。
  • 不要发到群里，不要截图公开；配对二维码里包含 Token。
  • Gist 是 secret，但不是加密存储；拿到链接和 Token 的人能看。
  • AI 分析会把题目文本发给 DeepSeek；图片识题会把图片发给阿里云。
  • 共享设备时，别人可能用到你保存的 Key；用完清除 Key。
  • 公开 GitHub 仓库里没有你的 Key；但不要把 Key 写进任何文件再上传。

15. 仍然卡住怎么办

准备这四项信息，发给维护者：

  1. 你打开的完整网址（包括 ?v= 参数）
  2. 手机/电脑的浏览器名称（Edge / Chrome / 华为浏览器 / Safari）
  3. 出问题的那一屏截图
  4. 错误提示原文，例如 401、404、Failed to fetch
不要发送完整 Token、API Key 或配对二维码截图。
